# Mobile free edition

`/mobile/free/` embeds `/mobile/free/app.html`, generated by `python3 build-free.py`
from the existing mobile editor. Assets, services, Google Calendar and clock code
are shared through a base URL. CI regenerates the HTML when either source changes.

Free access is scoped to the exact app pathname, not query strings, cookies,
purchase documents or stored entitlement. The paid entry points retain their
server-confirmed paid document checks. Free mode does not import Firestore or
read/write purchases. Optional Google authentication and calendar reauthorization
remain available; signout leaves free editing available. Calendar OAuth tokens
stay in memory. Firebase rules and Stripe settings are unchanged.

Layouts, matches and scores remain in the same origin-local browser storage,
shared with the existing edition. This is device/browser data, not account cloud
storage. The pre-existing cloud adapter is unconfigured; this release does not
create a new cloud service or claim device synchronization.
